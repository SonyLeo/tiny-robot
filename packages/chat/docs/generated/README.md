# Generated And Derived Artifacts

这个目录用于存放从重构长文档里抽出的高频派生事实表。

当前阶段它们可以是人工维护的派生索引，但不是新的权威 contract。

当前已建立的派生 artifact：

- `runtime-owner-table.md`
- `config-bridge-matrix.md`
- `slot-catalog.md`
- `page-region-contract.md`

## 1. 适合放这里的内容

- runtime owner table
- config bridge matrix
- slot catalog
- page region contract
- public surface intent index

## 2. 不适合放这里的内容

- 重新定义新的 API contract
- 重新定义新的 phase gate
- 脱离源文档单独演化的设计讨论
- 临时会议口径

## 3. 维护规则

- 每份 artifact 都应标明来源 source docs。
- normative docs 变化后，派生 artifact 要在同任务里同步。
- 如果某份 artifact 还不能稳定维护，就不要把它假装成 source of truth。
