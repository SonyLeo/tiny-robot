# Chat Web Component: verification slice

Date: 2026-09-26. This is a prototype and evidence record, not a public API or release package.

Update 2026-09-27: controlled comparison identifies `inlineDynamicImports: true` as the key trigger with the existing aggregate dependency graph. Default WC builds now allow dynamic chunks, retaining existing component source and dependencies. The fixed directory contains four JS files totaling 650.2 kB gzip and one CSS file at 55.7 kB gzip. The size tables below retain the 2026-09-26 investigation baseline. See [BUNDLE-SIZE.md](./BUNDLE-SIZE.md) for current reproduction commands, diagnosis and checks.

Design and acceptance record: [DESIGN-REVIEW.md](./DESIGN-REVIEW.md) maps the implemented first-version contract to native HTML/Angular consumption and remaining decisions. The package is not published.

## Reproduce

From `packages/chat`, run `$env:CHAT_WC_ANALYSIS_VARIANT='baseline'; pnpm exec vite build --config vite.web-component.config.ts`, then `node verification/web-component/check-size.mjs`. Set the variant to `inline` and build again to reproduce the original oversized output. Run `node verification/web-component/server.mjs`. Open `http://localhost:4178/` for the fixed bundle or `http://localhost:4178/?bundle=inline` for the original single-file setting. The older direct-import experiment remains at `?bundle=direct` when its artifact has been built. Services on 4178, 4179 and 4180 were stopped after this run; generated bundle directories are kept locally and regenerated by the build commands, while source, reports and tests are committed.

From `packages/test`, run `pnpm exec playwright test -c playwright.wc.config.ts`.

- Component type check, production build and declarations: passed after restoring the original component imports and dependency manifest.
- WC Chromium: 11 passed. Includes relocated entry/CSS/Markdown/DOMPurify URLs, actual Markdown rendering, plus the original DOM contract, lifecycle and streaming checks.
- Vue Attachments/Mention/Suggestion regression: 36 passed on the final component build.
- Original four Shadow DOM component edits remain unchanged. The final size fix introduces no component-source, manifest, ordinary Vue external-rule or kit change.
- At the verification-slice stage, native HTML used the fixed output directory directly; independent Angular installation and performance checks were added later with the formal package below.

## Formal package consumption: 2026-09-27

`@opentiny/tiny-robot-chat-web-component` is a separate ESM package built from the real `TrChat` entry. Its tarball installs into a blank native HTML host and an Angular 21.2.24 production host without a host Vue dependency or kit Angular adapter. Both installed entries have the same SHA-256 as the package build. The source CSS is inserted into each ShadowRoot from the entry JS, so the tarball has no separate CSS request. The original Angular production failure was `/style.css` returning 404 and preventing `ready`; the rebuilt host has no failed asset request.

正式包测试：`packages/test` 下 `pnpm exec playwright test -c playwright.wc-package.config.ts` 为 12/12，`playwright.wc-angular.config.ts` 为 2/2。验证切片 Chromium 11/11、普通 Vue 附件/Mention/Suggestion 36/36 和普通 Vue Chat 类型及构建均在本轮复跑通过。完整 MCP/附件交互、浮动布局、其他浏览器、移动端、长期泄漏和正式发布尚未验收。具体公开用法与限制见 `packages/chat-web-component/README.md`。

Angular 21 生产重构建成功，但示例工程发出默认预算警告：初始 chunk 为 2.15 MB 原始大小，超过 2.00 MB 上限约 146 kB；CLI 估算初始传输约 469 kB。这与独立包全部 JS 文件 gzip 706,680 B 的统计口径不同，也不是浏览器网络实测。发布评审应决定宿主初始体积预算及是否按实际页面需求延迟加载 Chat；本轮未通过调高预算掩盖警告。

此前同机一次五样本记录为原生 184 ms、Angular 180 ms；最终重建后复测为 243/347 ms。两轮都在已启动的浏览器进程内使用新 context 和本机静态 HTTP，不能推断线上首屏，也不足以制定性能阈值。最新原始样本存于 `verification/chat-web-component-performance.json`。

The HTML host imports only `dist-web-component/index.js`; it does not load Vue or TinyRobot global CSS. The bundle mounts real `TrChat`, Chat runtime, kit conversation and Sender in two real ShadowRoots. The mock response provider releases chunks on demand.

## Failure and fix evidence

- Initial browser run: `process is not defined` before `ready`; the prototype build now replaces `process.env` at build time.
- Initial suggestion run: popup root was `document`, expected `ShadowRoot`. `Sender` suggestion and mention now append to the editor's theme container or ShadowRoot, retaining `body` in ordinary pages.
- Source review exposed `document.activeElement` in menu key handling. History and dropdown menus now use the keyboard event target; the history menu arrow check passes in ShadowRoot.

## Open for design review

- First-version default: instance-local in-memory conversations. A page refresh or element teardown clears history; persistence is deferred and must be designed with identity, storage, migration and privacy rules before being offered.
- Bundle recommendation revised on 2026-09-27: allow dynamic chunks in the WC build. The subpackage-import source experiment was reverted after a single-setting comparison demonstrated better size with a narrower change. Component source, dependencies and normal Vue external rules match the start of this investigation. Full MCP interactions and the remaining consumer matrix are pending.
- `responseProvider` updates after `ready`, title/color-mode property reflection and cross-framework TypeScript declarations have since been implemented in the formal package. Complete event vocabulary and method edge cases still need acceptance checks.
- Floating layout still teleports to `body`; this slice verified the normal layout only. Other overlays, MCP, attachments and external state ownership remain outside this slice.
- Angular 21 and actual Chrome were subsequently verified with the formal tarball; Edge and other browsers remain outside the agreed matrix.

## Bundle-size investigation

All rows use the same Vite production settings and real `TrChat` entry. Numbers are actual output-file bytes, divided by 1000; gzip uses Node `zlib.gzipSync`. A variant changes imports at build time only. `bundle-report*.json` contains Rollup module contributions before minification, which are useful for attribution but are not compressed file sizes.

| Variant | JS kB | JS gzip kB | CSS kB | CSS gzip kB | Interpretation |
| --- | ---: | ---: | ---: | ---: | --- |
| Baseline | 9,137.0 | 2,349.7 | 1,444.2 | 188.1 | Self-contained prototype |
| Direct OpenTiny Vue subpackages | 2,742.9 | 764.8 | 519.2 | 66.7 | Same Chat behavior in Chromium smoke test |
| Baseline without MCP panel | 9,127.5 | 2,344.4 | 1,443.2 | 188.0 | MCP panel is not the main cause |
| Direct without MCP panel | 2,733.4 | 758.9 | 518.1 | 66.5 | Only about 5.9 kB JS gzip saved |
| Baseline without demo suggestion | 9,137.0 | 2,349.7 | 1,444.2 | 188.1 | Demo suggestion is negligible |
| Direct without component global CSS | 2,742.9 | 764.8 | 485.1 | 62.0 | Breaks required Chat styling; attribution only |
| Direct without dependency CSS | 2,742.9 | 764.8 | 203.6 | 30.1 | Breaks dependency styling; attribution only |

The direct-subpackage experiment saves 1,584.9 kB of JS gzip and 121.4 kB of CSS gzip, reducing the combined gzip payload from 2,537.8 to 831.5 kB (67.2%). Baseline transforms 4,044 modules; direct imports transform 1,754. The installed `@opentiny/vue` 3.31.0 aggregate entry statically imports its many subpackages. In Rollup's pre-minification module report, direct imports remove `echarts` (2.26 MB), `zrender` (543 kB), `@opentiny/vue-grid` (583 kB), `@opentiny/fluent-editor` (394 kB), Quill and other unrelated packages. `@opentiny/vue-renderless` drops from 1.89 MB to 294 kB. These module figures cannot be added to estimate gzip savings.

The remaining direct-import JS includes Vue runtime, TinyRobot components, Tiptap/ProseMirror and Markdown rendering. In CSS isolation builds, removing the component global entry changes CSS by about 34 kB, and removing dependency styles changes it by about 316 kB. Both experiments break appearance; the remaining CSS includes Chat and component styles. The relative contributions are build-dependent and should be remeasured after the final packaging design.

For the first publishable build, a provisional review gate is JS gzip <= 1,000 kB and CSS gzip <= 100 kB, with the direct-import result (765/67 kB) as the observed reference. The gate must also require a standalone native HTML and Angular host, complete ShadowRoot styling, two-instance behavior, and a cold-load browser measurement. Meeting the byte limits alone does not establish compatibility or acceptable startup time.

The first direct-import browser attempt failed with 0 of 2 `ready` events after 15 seconds: the verification page requested `/dist-direct/index.js` instead of `/verification/web-component/dist-direct/index.js`. The corrected page and full 10-test Chromium run pass. Playwright cleared its failed-run screenshot and trace on the next run, so the failure is preserved here as an observed result rather than as image/trace files. This was the state of the bundle investigation before formal package and Angular consumption were added.
